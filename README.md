# China Flag

A full-screen, animated Chinese flag for [china.curtiscovington.com](https://china.curtiscovington.com).

The flag is drawn procedurally and rendered as a WebGL cloth surface. It has no runtime dependencies and respects the operating system's reduced-motion preference.

## Local preview

```bash
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Actions publishes the contents of `dist/` to GitHub Pages on every push to `main`.
